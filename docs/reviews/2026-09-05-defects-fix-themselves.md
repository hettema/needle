## What the build learned the plan got wrong

- "A fix lane counts against the number from its Start to its fold" cannot bound the dial: a planning session is a session on a subscription. It counts from the planning session's start (disposition 6).
- "The board then opens the Start door itself" needs a home the Start ratchet allows. The ratchet's method (only the pressed modules reach Start) was rewritten at the altitude of its intent (every start is the owner's: his click, or his ruling through the dial), and `api/dial.py` is the one module that opens the door as the machine.
- "A session that finds the fix implies a decision that is the owner's writes nothing but a note on the card and stops" needed a row kind: the ASK row, which is already amber and already the owner's move; the dial reads the card as his from it and never rewrites the document.
- "The plan carries an item that makes the class loud" needed a machine-readable form for `needle fixes` to count: the plan's `Class:` head line, which the planning brief asks for.
- "Whose Start would otherwise be open" at planning time is not the Start door's verdict — a suggestion has no gate, so Start is closed for that reason alone; the beat checks the parts that can be known then (no lane, no planning session, a place to run) and the door judges the rest once the plan names its terrain.
- The reconcile seam (disposition 1): the README's own instruction to move the carried suggestion in the same commit had been followed once before this lane, and that once broke.
