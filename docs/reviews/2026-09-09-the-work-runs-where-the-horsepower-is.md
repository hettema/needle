## Dispositions

1. [seam] **A group's owner was matched by pid alone across machines.** `board/dial.py::who_is_home` looked every group's pids up in one map of every session's pid, so a group read on the rented machine could read as home to a laptop session holding the same number and never be swept, or a stranger there be called a session here. FIXED: the map is keyed by `(machine, pid)`, both stamped by the runtime that read them; a floor case holds two groups with the same pid on two machines and reads the laptop's home and the rented one's nobody home.
2. [feature] **The Start preview never named the machine, while the plan's ruling said it does when the board knows more than one.** `board/lane.py::driver` built its words from the rung alone. FIXED: it appends `on <machine>` when the placement carries a name, which `api/loops.py::_placement` blanks on a one-machine board, so every existing face reads as before.
3. [seam] **A fresh session from a remote session's transcript is judged against the wrong transcript.** `runtime/windows.py::look_command` reads the transcript's size here (`machine.transcript_size`) for a session that ran on the other machine, finds nothing, and asks for a resume there rather than a fresh brief; the other machine's own `claude --resume` then holds the size rule. NO CHANGE: a resume that the other machine refuses for size is a window whose first line says so, loud and once, and the fresh-brief branch is a size optimisation, not a claim; noted for the live read of item 4.
4. [record] **The desktop's `needle tell` keeps its own ledger of how a popup was answered, beside the desktop's store, not beside the board's.** The loop writes that ledger's path and never reads it back (`api/loops.py::_tell_owner` writes `told.log`; no reader), so nothing the board shows depends on which machine holds the file. NO CHANGE; item 3's live read says which machine the plan's own reading of card #41 should read the ledger on.
5. [seam] **A stray group on one machine could get a live group on the other stopped.** The sweep's memos were keyed by unit alone, and the machine map by unit; with the same unit on both machines the rented one's destination was overwritten. FIXED: every memo and the eligibility are keyed by `(machine, unit)`, the owner is alive only on the group's own machine, `ScopeState` carries its machine, and the store's `who_is_home` case reads two like-named groups apart.
6. [seam] **A failed session read became evidence that sessions ended.** `Runtime.sessions` dropped every row of a machine that did not answer, so its lanes read as ended, a death could be named, a group swept. FIXED: the last rows read stand, the machine is named in `Runtime.unread` with the transport's words, `scopes` offers no group of an unread machine, and the loop names no death, brings nothing back, releases nothing and stamps no worktree gone for a session or record on one; a floor case turns the rented host off and reads the lane still live and the machine unread, then on again.
7. [seam] **The real `ssh` lost the quoting around the login-shell script.** `bash`, `-lc` and the line were three `ssh` arguments; `ssh` joins them, so the other side's shell ran `needle` alone. FIXED: one quoted argument (`runtime/machine.py::remote_argv`); the stand-in now joins the words and parses them with `shlex` as that shell would, refusing a `bash` line that does not carry its script whole, and runs a plain command line (a terminal's `ssh -t host -- tmux …`) as given.
8. [seam] **Calling a colleague on another machine invoked the local launcher.** NO CHANGE to the call's path; REFUSED by name instead: the note and the answer are files here, and the call cannot travel yet, so `Runtime.call` answers dead with the machine's name rather than act on this machine's processes for a session that is not here. Item 4's live read names the call's travel.
9. [feature] **A card in a machine's own record bypassed the room, and the machine chosen never rechecked its floor at the launch.** FIXED: a full ground refuses with that machine's numbers and "runs nowhere else"; `Runtime.start` and `start_windowless` read this machine's room at the moment of a local launch and refuse in the head's words, which is what the other machine's own `needle start` does when asked; a one-machine board places as before and refuses at the door and the start in the words it had (the floor's memory suite reads the same sentence as before).
10. [seam] **Forgetting a machine with work on it routed that work here.** FIXED: `remove_machine` refuses while a lane record or a session record names the machine; a name the board no longer knows is a machine with no host, so everything routed to it answers unreachable by that name and nothing runs here in its stead.
11. [seam] **Recovery gated on this machine's room and resumed on another.** FIXED: `_recover` and `_park_lifts` read the room of the machine the session runs on (`_room_of`), read fresh; the resume goes to that machine, where the worktree is.
12. [seam] **A lost launch reply was a dead launch, and a remote session's kill was counted against this machine.** FIXED: a timeout is `RemoteTimeout` and the launch answers `unconfirmed` with "may have landed", never dead (a floor case lays a slow host); a sighting carries the machine the process was seen on, and `killed_on` reads the sighting first, the slot record second, this machine last.
13. [seam] **The board read a remote lane's worktree on its own filesystem.** The largest finding: `worktrees`, `edits`, `lane_files`, `branch_tip`, `lane_folded`'s tip, the plan's progress and the close's dispatches were all local reads, so a rented lane would have read as gone — "the disk wins" — the moment item 4 went live. FIXED: `Runtime.worktrees` merges every machine's checkouts and remembers which machine each was seen on; `edits`, `lane_files`, `lane_tip`, `lane_docs`, `dispatches` and `transcript_size` go to that machine over the wire (six new verbs, each answering a domain value); the lane record says which machine; a machine that does not answer keeps the paths it was last seen with, never gone. A floor case with a real lane worktree reads each of them over the stand-in `ssh` for a lane placed on the rented machine and with no wire for one placed here.
