## What the build learned the plan got wrong

- The plan said `writable_roots` was the door because a linked worktree's `.git` is a file pointing into the main copy. The door is `writable_roots`, but the reason is that the sandbox denies `.git` writes everywhere — so the fix is four paths, not one, and it would have been wrong even in a repository with no worktree at all.
- The plan said the lane would need no network and the runtime would fold for it. A lane that can commit can also run its suite and its own fold, and giving it a second fold path would have been the only new shape in the whole card. The intent — "folds through the same door, and red never lands" — is better served by the same door.
- The plan expected two `fable` guesses; there were three, and the third was in the page.
- The plan did not say what happens to the Start label when the rule names no model. It loses a word today. That is the guess leaving, and the machine's card brings the word back as a fact.
