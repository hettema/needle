## Intent

Hello Revenue is built by sessions that arrive with no memory of each other, on one trunk, under one owner who ranks and starts. INTENT's fourth lesson, written from the first board's fear, says the board refuses a collision unless the owner overrides it. Last night showed what that rule protects: nothing the fold does not already protect, at the cost of most of the machine's capacity. A lane rebases on the trunk and runs the full suite on the levelled tree before it may fold; the fold is a fast-forward that refuses when the trunk moved. That is how a large team on git works: nobody locks a file, the second to land pays the merge, and the suite is the judge. A lock on file paths does not catch the one conflict that matters, two lanes changing one behaviour in incompatible ways with no textual overlap; the suite at the fold does.

What will be true when this is done, in the owner's words: **as many sessions as the machine can hold work concurrently, safely, at the same quality, without crashing the machine.** Shared ground is shown on both cards and settled at the fold. A plan that genuinely cannot run beside another says so in its own head, and that is the one thing that holds a Start. The dial's number is a ceiling the machine lowers when memory runs short, never a count of records. A lane that has folded and closed gives its memory back.

What does not change: the fold's discipline (rebase, full suite, fast-forward), which is the guard this plan leans on; `drift`, which names two running lanes editing the same file on both cards; the one move that is the owner's; the model rule.

### 3. The dial's number is headroom the machine reads

Two changes to `board/dial.py` and `api/dial.py`. First, a fix lane at the planned stage whose Start door is closed (parked, waiting on a Sequencing card, nowhere to run) does not count against the number: it is no process, and last night four such cards held four slots while fourteen eligible defects waited. The planning stage still counts, which bounds how many plans are written ahead. The head shows *held* beside *live*, so a night like that one reads *4 held, 0 running*. Second, before the dial opens a planning session or a Start, `runtime/machine.py` reads `/proc/meminfo` and the beat takes nothing while available memory or free swap is under the floor; the head says *the machine is full* with the two numbers. The floor is one constant with its why: 3 GB, because a fix lane peaked at 3.1 GB last night (#385, `systemctl show MemoryCurrent`) and systemd-oomd acts at 90 percent of both. The loop below moves it. Done means: on the dial fixture, a planned card with a closed door is not counted and the next eligible defect is taken; the fake machine reporting 2 GB available stops the beat and the head reads *the machine is full: 2.0 GB available, 3 GB needed*; the number the owner set is never raised by the board. Hands out: nothing; the constant is a judgment.

### 4. A lane that folded and closed gives its memory back

When the loop moves a card out of Executing on a fold the board has recorded and a close it has taken, the lane's session is stopped through the runtime the way a reading session whose turn is over is (`api/loops.py::tend_windowless`), and the card's record says so. Last night five finished lanes stayed resident for hours holding about a gigabyte between them while the machine sat at its ceiling. A lane that ended any other way (died, walled, stopped by the owner) is left as it is: its state is evidence. Look on a finished card opens a fresh session in the project's checkout, as it does for a card with no lane. Done means: on the floor, a lane that folds and closes is gone from `needle sessions` within one reconcile and the card carries the row; a lane that died is untouched; memory held by lane scopes after a fold is read in the close-out before and after.

## Rulings
Recorded from the conversation; each overturnable by the owner on the card.
1. **File overlap is not a reason to refuse.** The fold is the guard: rebase, full suite, fast-forward. Rejected: a lock with a size threshold — a threshold is a guess about merges the fold judges exactly.
2. **The override door goes.** One way to start a card. Rejected: keeping *Start anyway* for the shared-ground case — a door that opens where the other already opens is ceremony.
3. **The plan's own word is the one hold.** A plan that cannot run beside another says which card it waits on; the board reads that, and nothing else, as a reason to wait. Rejected: inferring incompatibility from terrain — that is the lock under another name.
4. **The number is a ceiling the machine lowers, never raises.** The owner sets the most; memory sets the rest. Rejected: the board raising its own number when memory is plentiful — the owner said four, and a dial that turns itself is the first board's deepest trap.
5. **A finished lane is stopped; every other ending is left as evidence.** Rejected: stopping every ended session — a lane that died says why only while its scope stands.
