## Intent

A project Dennis puts on Needle is built the way we work from its first session, on this laptop or the next one, and what that project learns about the way we work comes back to the one text every project reads, through the board, so the next project starts wiser. Today the doctrine exists twice — `docs/HOW-WE-WORK.md` here, the published statement Needle's `docs/INTENT.md` says is written once, and the global `~/.claude/CLAUDE.md` in the machine repo, the text every session on this laptop actually obeys — in different words, with one sentence held in step by a reader omarchy #19 had to write (`doctrine_twins_drift()` in `machine`) and twelve sections held by nothing. `needle add` registers a path and imports 0.1 cards; it says nothing about doctrine, so a project on a second machine would enter with none. After this plan: one text, HOW-WE-WORK, is the constitution; the board's door says whether the machine a project sits on delivers it; every rule in it says what holds it, in HR's three words and no fourth, and a rule held by nothing says so with a card and a date rather than a fourth word; a learning about the way of working travels as a suggestion marked `Fix: his`, becomes a card, and edits the one text on that card and nowhere else; and the machine's part — pointing every agent of any make at the one text and retiring the twin — is a card on the machine's board, written here, not done here.

What this plan does not decide: the words. Every sentence that moves, merges or is dropped moves by his ruling on a table he can read without opening code (item 1), asked for from inside the running lane through the board's own question-and-answer door. What it does not touch: how a colleague is called (#51), how Codex enters (omarchy #19, live), any provider's lifecycle, and any project's own ratchets (Needle's fourteen, HR's suites, the machine's four).

## Rulings
1. **The words are his.** No sentence of the constitution is dropped, moved or merged by a session's taste; item 1's table is the instrument, the lane's question through the board is how it is put to him, and his answer through the Answer door is the ruling. The board starts cards, not items, so the ruling is asked for from inside the running lane and lands on the card's history.
2. **One text, not a contract beside the texts.** Codex's "portable doctrine contract" is HOW-WE-WORK itself; a new artefact beside it and the global file would be a third source and the map §8 refuses.
3. **An adapter holds zero doctrine words.** Links, caps, hooks, trust, version lines and facts about a laptop; omarchy #19's `home/.codex/` is the proof it can be done. A sentence a session obeys that appears in an adapter is a defect.
4. **One reader per text, in the text's repository.** HOW-WE-WORK's stances are read by a Needle ratchet, the machine CLAUDE.md's by `machine check`, HR's by HR's suite. No central register; the counts a reader prints are the only map.
5. **The door says, the person decides.** `needle add`'s entrance line is a finding, never a refusal: a project on a machine with no entrance is still a project on the board.
6. **A doctrine edit is intent-bearing by definition.** It travels as `Fix: his` and lands on a card; a commit hook, not a convention, holds it.
7. **Three stances, and debt is not one of them.** Held, traced, convention are the only ways a rule is held (HR's register: "there is no fourth"). A rule held by nothing says so with a card and a date, is counted apart, and is refused by the reader the day the date passes or the card is gone. The plan lands with debt and never calls it defence.
