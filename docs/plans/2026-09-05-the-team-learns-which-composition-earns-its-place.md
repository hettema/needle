## Intent

AI colleagues contribute across Needle projects wherever evidence shows their composition delivers the owner's intent better, with quality invariant and speed and cost won inside it. The organisation, not Dennis's memory, measures which composition works for which kind of work, keeps a composition only as a default that evidence earned, and re-tests it when a model changes. Dennis judges perceptual and intent-bearing outcomes; the colleagues design and operate machine-readable outcome, quality, rework, escape, time and cost loops and bring him only decisions that require his intent.

This is not a new measurement platform. The system is already the authority: review rings, corrections, defect lineage, send-backs, commits and burn records are the evidence. This card adds only the missing declaration of which composition ran and one reader that joins those existing facts.

## Items

### 1. A card declares its composition before the work

Add one typed, corpus-owned declaration for the composition being tried: accountable hand alone, same-make challenge, or different-make challenge, with the models named. It is predeclared before the design artefact is judged and appears on the card and in its close-out. No role is permanent and no composition is mandatory on every card. Done means: the board reads exactly one declaration when present, says honestly when absent, and no session can rewrite the declaration after the outcome to make a result look better.

### 2. One reader joins evidence that already exists

For comparable design work, read and attribute: material corrections made before build; review findings by inside, adjacent and outside ring; defects later filed against the card; send-backs and stops; commits within a week that fix or revert the fold; tokens and wall-clock from the existing burn and lane timestamps. Do not copy these facts into a new event stream. Done means: one generated reading can be reproduced from corpus, board and git facts; deleting or changing a source fact changes the reading; there is no hand-maintained scorecard.

### 3. Quality decides first; efficiency breaks a quality tie

Compare one high-judgment, reversible work shape across three observations: accountable hand alone, same-make challenge, and different-make challenge. Corrections before build and escaped defects after close decide first. Time and tokens are always shown but choose only between compositions that do not differ on quality. Findings are presented with the work shape and sample count so harder assignments cannot silently make a composition look worse. Done means: the reader refuses a winner from incomplete observations, preserves the underlying facts, and can state “insufficient evidence” without routing by opinion.

### 4. A learned default remains falsifiable

A composition earns the default for that work shape only if the comparison's predeclared threshold is met. One card in four explores a non-default composition, and any participating model change makes the old evidence stale and triggers a new comparison. A practice change is proposed as a doctrine suggestion with `**Fix:** his`; this reader never silently becomes a router. Done means: fixtures cover earned, tied, insufficient and stale conclusions; exploration occurs without overriding a card-specific intent; every proposed default links to its observations and requires Dennis only for the doctrine decision.

## Acceptance criteria

1. Three comparable observations are readable from existing system evidence, with #54 included only if its different-make challenge actually happened.
2. The output orders corrections and escapes ahead of time and tokens, names confounds and sample size, and never calls debt or missing evidence a win.
3. Every source fact has one authoritative home; the new code stores only the predeclared composition and derives the rest.
4. A model change and the one-in-four exploration rule can both dethrone a default through fresh evidence; no permanent “Claude implements, Codex reviews” role exists.
5. Any doctrine change is a `Fix: his` suggestion and not an automatic routing mutation.

## Loop

We think different-make challenge will earn a place on high-judgment design work by surfacing material corrections before build without increasing escaped defects, while simpler work will often earn a single accountable hand. Fixed before the observations: different-make becomes the proposed default for this work shape only if it produces a material correction missed by the accountable hand's own review in at least two of its first three eligible trials and no trial has a defect filed against it within fourteen days. Time and tokens are recorded from the first trial and decide only a quality tie. If the threshold is not met, the current single-hand default stays; if work shapes are not comparable, the result is insufficient evidence; when a named model changes, the comparison is stale and runs again.

## Deliberately not

- A second telemetry stream, manually maintained scorecard or universal scalar productivity score.
- Two AIs on every card.
- Automatic doctrine edits or permanent provider roles.
- Asking Dennis to judge test mechanics, defect attribution, token counts or elapsed time.
