# The collapsed card says whether it can start now, and starts from there

**Found by:** the owner, 2026-09-04, on Needle's own board with one lane
running: "how do I see if I can kick off cards concurrently? … the closed
card should clearly show if it's free to kick off", and "do you think we
should have a start button on the card (its collapsed view)?"
**Kind:** idea

## Observation

Today the answer to "can this run beside what is running" lives only on the
open card: the Start door's reason names the collision, and a card with no
gate simply shows no Start at all (the owner looked at a suggestion in Up
next and found Discuss, Open, Copy path — nothing said "not startable, and
why"). Reading the whole board for what can start means opening every card.

## Done means

- Every collapsed card in Planned and Up next carries one pill that answers the
  question at a glance: **free** (gated, no collision, nowhere-to-run not an
  issue), **collides with #N** (the files named on hover), **no gate** (a
  suggestion or a plan without an effort gate; Discuss it to write one), or
  **nowhere to run** (every subscription spent).
- A free card carries Start on its collapsed face, the same door as the open
  card's, with the same confirmation sentence; a colliding card carries
  "Start anyway" only on its open face, where the reason is in front of him.
- The open card of a gateless document shows Start closed with its reason in
  text, like every other closed door.
- The pill is recomputed on every read from the same facts the Start door
  uses (one function), never a second judgment.
